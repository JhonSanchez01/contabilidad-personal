## 🚀 Cómo subir a un servidor web

### Opción 1: GitHub Pages (Gratis)

1. **Crea un repositorio en GitHub**
   ```bash
   git init
   git add .
   git commit -m "Primera versión"
   git remote add origin https://github.com/tu-usuario/contabilidad-personal.git
   git push -u origin main
   ```

2. **Activa GitHub Pages**
   - Ve a Settings > Pages
   - Selecciona "Deploy from a branch"
   - Elige la rama "main"
   - Tu sitio estará disponible en: `https://tu-usuario.github.io/contabilidad-personal`

### Opción 2: Netlify (Gratis)

1. **Sube los archivos a Netlify**
   - Ve a [netlify.com](https://netlify.com)
   - Arrastra la carpeta del proyecto
   - Tu sitio estará disponible automáticamente

### Opción 3: Vercel (Gratis)

1. **Conecta con Vercel**
   ```bash
   npm install -g vercel
   vercel
   ```

### Opción 4: Servidor propio

1. **Sube los archivos a tu servidor web**
2. **Configura el servidor para servir archivos estáticos**
3. **Asegúrate de que el archivo `index.html` esté en la raíz**
