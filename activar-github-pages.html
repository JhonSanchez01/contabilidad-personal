🌐 Activar GitHub Pages

Pasos automáticos:

  1. Ve a Settings → Pages
  2. Source: "Deploy from a branch"
  3. Branch: "main"
  4. Folder: "/ (root)"
  5. Haz clic en "Save"

Tiempo de activación: 2-5 minutos

  • ✅ Chrome / Safari / Firefox / Edge
  • ✅ HTTPS automático
  • ✅ Dominio personalizado

🔧 Configuración adicional:

Una vez activado, puedes:

  • Cambiar el nombre: Settings → General → Repository name
  • Dominio personalizado: Settings → Pages → Custom domain
  • Analytics: Settings → Pages → Google Analytics
