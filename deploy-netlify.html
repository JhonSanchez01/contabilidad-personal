🚀 Deploy Automático a Netlify

📋 Paso 1: Crear repositorio en GitHub

Primero necesitamos crear el repositorio en GitHub:

Crear Repositorio

Configuración:

  • Nombre: contabilidad-personal
  • Descripción: Aplicación web de contabilidad personal
  • Público (para que sea gratis)
  • NO marques "Add a README file"

📁 Paso 2: Subir archivos a GitHub

Una vez creado el repositorio, sube estos archivos:

index.html
estilos.css
script.js
README.md

Método rápido:

  1. Haz clic en "Add file" → "Upload files"
  2. Arrastra los 4 archivos de tu carpeta
  3. Escribe un mensaje: "Primera versión"
  4. Haz clic en "Commit changes"

🔗 Paso 3: Conectar con Netlify

Ve a Netlify y conecta tu repositorio:

Ir a Netlify

Pasos en Netlify:

  1. Haz clic en "Sign up" (arriba a la derecha)
  2. Selecciona "Continue with GitHub"
  3. Autoriza Netlify para acceder a GitHub
  4. Haz clic en "New site from Git"
  5. Selecciona "GitHub"
  6. Busca tu repositorio: contabilidad-personal
  7. Haz clic en "Deploy site"

🎉 ¡Listo!

Tu aplicación estará disponible en:

https://tu-sitio.netlify.app

Tiempo de espera: 1-2 minutos

Ventajas:

  • ✅ HTTPS automático
  • ✅ Dominio personalizado gratis
  • ✅ Deploy automático al actualizar
  • ✅ Analytics incluidos

🔧 Configuración adicional

Una vez desplegado, puedes:

  • Cambiar el nombre: Site settings → Change site name
  • Dominio personalizado: Domain settings → Add custom domain
  • Analytics: Analytics → Enable analytics
