🚀 Subir Contabilidad Personal a GitHub

📋 Paso 1: Crear repositorio en GitHub

Ve a GitHub y crea un nuevo repositorio:

Crear Repositorio

Configuración:

  • Nombre: contabilidad-personal
  • Descripción: Aplicación web de contabilidad personal
  • Público (para que sea gratis)
  • NO marques "Add a README file"

📁 Paso 2: Subir archivos manualmente

Una vez creado el repositorio, sube estos archivos:

index.html
estilos.css
script.js
README.md

Método rápido:

  1. Haz clic en "Add file" → "Upload files"
  2. Arrastra los 4 archivos de tu carpeta
  3. Escribe un mensaje: "Primera versión"
  4. Haz clic en "Commit changes"

⚙️ Paso 3: Activar GitHub Pages

Ve a Settings → Pages y configura:

  • Source: "Deploy from a branch"
  • Branch: "main" o "master"
  • Folder: "/ (root)"
  • Haz clic en "Save"

🎉 ¡Listo!

Tu aplicación estará disponible en:

https://JhonSanchez01.github.io/contabilidad-personal

Tiempo de espera: 2-5 minutos para que se active

⚠️ Alternativa más fácil: Netlify

Si prefieres algo aún más rápido:

  1. Ve a netlify.com
  2. Arrastra tu carpeta completa
  3. ¡Listo! URL automática en segundos
